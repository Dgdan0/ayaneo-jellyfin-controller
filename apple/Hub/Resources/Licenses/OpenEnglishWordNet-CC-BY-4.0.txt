JellyHub bundles a derived SQLite index containing headwords, parts of
speech, and definitions from the 2025 JSON release (the same file as the
Pocket DS app). This changes the data format and omits relation graphs,
examples, and other source metadata. The Open English WordNet Community does
not endorse this application.
